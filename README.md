# Exercise 1: JavaScript Pixel Drawing

This is a fork of the NCSU Computer Graphics Exercise 1 starter repository.
It draws a rectangle pixel by pixel on a 512-by-512 HTML canvas.

## Changes

The starter rectangle was modified in all three suggested ways:

- **Color:** changed from black to bright blue (`rgba(37, 99, 235, 255)`)
- **Size:** changed from 50 by 25 pixels to 320 by 224 pixels
- **Position:** moved from `(50, 50)` to `(96, 144)`

The original `Color`, `drawPixel`, and `main` structure is preserved.

## Run locally

Open `index.html` in a modern web browser. No installation or build step is
required.
